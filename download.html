01 Install

What the installer does.

Runs without administrator rights

A per-user install on purpose. No UAC prompt — and, the reason that matters later, an auto-updater can replace the files without elevation.

Installs WebView2 only if it is missing

EIMC runs in a native Microsoft Edge WebView2 window. The installer carries the evergreen bootstrapper and runs it silently when the runtime is not already present.

Creates shortcuts, offers a desktop icon

Start-menu entry always; the desktop shortcut is a tick-box during setup.

Never writes inside the install folder

Your charts, drawings, recordings and credentials live in %LOCALAPPDATA%\EIMC and are left alone by both install and uninstall. Override with EIMC_DATA_DIR.

A SmartScreen warning is possible. Until the code-signing certificate is in place, Windows may show “Windows protected your PC” for a new publisher. Choose More info → Run anyway. Both the app and the installer get signed once the certificate is in hand.
Uninstalling. Settings → Apps → EIMC Terminal, or the Start-menu uninstaller. It removes the program and the WebView2 cache beside it, and leaves %LOCALAPPDATA%\EIMC untouched — so reinstalling later brings your layout, drawings and recordings back with it.
Prefer to run from source? pip install -r requirements.txt, then python server.py, and open http://127.0.0.1:8765. Or double-click run.bat, which does both. Keep the console window open — closing it stops the server.
02 Connect

Connect your Dhan account.

EIMC is a terminal for your own Dhan account, so the data is yours and nothing is resold to you. Three steps, about a minute.

Generate an access token

web.dhan.co → Profile → DhanHQ Trading APIs. Set the toggle to Access Token, then click Generate.

Paste it into EIMC

Open Settings (the sliders icon, top right). Paste your Client ID and the token, then click Save & test.

Check both lights

You should see Login OK and Data APIs OK. Chart data needs the Data APIs subscription — Login OK on its own is not enough.

Tokens expire every 24 hours. Dhan issues a fresh one daily, so pasting a new token each morning is part of the routine — not a bug.
No credentials? Use demo. Choose Demo (synthetic) and the whole terminal runs on generated data: every mode, every indicator, bar replay included. That is the free tier, and it never expires.
For live orders only. Elite’s real-money orders need the Trading APIs enabled, and Dhan may require your IP to be whitelisted: web.dhan.co → DhanHQ Trading APIs → Static IP Setting. Credentials are stored in the Windows Credential Manager, never in a file in the install folder.

04 Requirements

System requirements.

Operating system
Windows 10 or 11, 64-bit (x64-compatible)
Runtime
Microsoft Edge WebView2 — bundled, installed silently only if missing
Privileges
None. Per-user install, no UAC prompt.
Display
Opens maximised; window default 1600 × 950, minimum 1100 × 700
Account
Dhan with the Data APIs subscription for live data · Trading APIs as well for live orders · none at all for demo mode
Markets
NSE · BSE · MCX
Data location
%LOCALAPPDATA%\EIMC, or wherever EIMC_DATA_DIR points
Network
The local server refuses any request whose Host or Origin header is not its own
